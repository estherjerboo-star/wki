Gestion de contenido y usuarios

La wiki es publica para todo el mundo, pero aqui se controla quien puede escribir. El administrador puede editar, meter y borrar contenido, y tambien borrar usuarios. El usuario editor puede modificar y meter contenido.

Roles y cuentas

Solo el administrador puede borrar usuarios o cambiar su rol. El rol `usuario` solo puede leer y enviar solicitudes, `usuario editor` puede meter y modificar contenido, y `administrador` controla todo.
